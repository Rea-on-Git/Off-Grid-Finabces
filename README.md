# This is Off Grid Finances 
This is a one hundred percent offline yet effective Financial tracker that perfectly fit the the offline theme
## Why and How 
I created this project because I was tired of constantly using Apps and Trackers that all these Ai features, online streaks and just annoying things that invade privacy for Ad information. When I saw the idea of No Internet this was the first thing that popped into my mind. I wanted to make it super simple, lightweight and fast with unnecessary and invasive features of modern day trackers. I also decided to make It CLI based to save as much time as possible when adding and removing transactions.

Now onto the how, this is actually a super simple project which uses essentially only python And Json files to work, This makes it quick and effective on all devices.

The Project can be run on any desktop computer just make sure to put it in a separate folder so the Json files don't get jumbled up

I have been coding for a moderate amount of time now but this is my first time uploading a project to Git Hub and To Hack Club so most of the things I learnt Had to with that.

The main thing I had an issue with though was getting the recurring transactions to work as I haven't really worked with automated scripts that much but It was super fun to learn to make it working with datetime in a new way and Forming various work arounds.

I also used a tutorial for the savings section just to double check something and looking at how to make the progress bar
